# Python Concurrency Sandbox

Учебный набор задач на Python для изучения многопоточности и механизмов конкурентного выполнения.

## Цель

На практике изучить работу с потоками, синхронизацией, `Future` и другими механизмами конкурентного выполнения в Python.

## Комплект 1. Потоки

В первой части рассматриваются базовые операции с потоками:

* создание нескольких потоков;
* загрузка файлов с использованием потоков;
* одновременное выполнение HTTP-запросов;
* вычисление факториала с использованием потоков;
* многопоточная быстрая сортировка.

## Комплект 2. Concurrency и Futures

Во второй части реализованы примеры:

* симуляция банковских операций с использованием `Lock`;
* асинхронная загрузка изображений с использованием `Future` и семафора;
* чтение и запись данных с использованием `Future`;
* синхронизация потоков с помощью `Event`;
* собственная очередь и рекурсивный блокировщик `RLock`;
* взаимодействие потоков сервера и клиента с использованием `Barrier`;
* параллельный поиск файлов в директории.
